## 💎 Project Overview

**AI Company Headquarters** is an enterprise-grade autonomous organization platform where hundreds of specialized AI agents collaborate under a strict 4-level management hierarchy.

- **Level 1: Founder (Yuvraj Soni)**: Supreme control, global oversight, binding approval authority, financial budget constraints.
- **Level 2: Central CEO AI (Aegis Prime)**: Company-wide management, strategy formulation, cross-department task delegation, operational health telemetry.
- **Level 3: Department Directors (23 Autonomous Divisions)**: Marketing, Content Creation, Social Media, Market Research, Competitor Intelligence, Photography, Image Editing, Video Production, SEO, Website Growth, Business Strategy, Sales, Customer Relations, Customer Support, Operations, Project Management, Finance Analysis, Data Analytics, Quality Control, AI Audit, AI Supervision, Technology, and Automation.
- **Level 4: Specialized AI Employees**: Pre-configured specialist agents executing operational deliverables.
- **Level 5 Oversight: Independent Supervision System**: Department Supervisors, Chief Supervisor AI, Chief QC AI, and Chief Audit AI operating with an immutable cryptographic audit ledger.

## 🚀 Getting Started

### 1. Prerequisites
- Node.js `v20+` or `v22+` (Detected: `v26.13.0`)
- Git

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Database Migration (Supabase)
To connect your production Supabase database:
1. Open your Supabase Project Dashboard.
2. Go to the **SQL Editor**.
3. Run the complete migration script located at:
   `supabase/migrations/20261102_initial_schema.sql`
4. Copy your project URL and Anon Key into `.env.local` (or configure via **Settings & API Vault** in the app).
